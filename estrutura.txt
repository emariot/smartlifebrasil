## 🔄 Collections Disponíveis

```javascript
// Produtos
collections.produto               // Todos os produtos
collections.produtosCasa         // Produtos categoria "casa"
collections.produtosEscritorio   // Produtos categoria "escritorio"
collections.produtosVida         // Produtos categoria "vida"

// Blog ✨ NOVO
collections.blog                 // Todos os posts (ordenados por data)
collections.blogGuias            // Posts categoria "guias"
collections.blogNoticias         // Posts categoria "noticias"
collections.blogDicas            // Posts categoria "dicas"
collections.blogReviews          // Posts categoria "reviews"
```

## 📝 Front Matter Padrão

### Para Produtos
```yaml
---
layout: produto.njk
tags: ["produto"]
categoria: casa                   # casa | escritorio | vida
produtoNome: Nome do Produto
marca: Marca
produtoDescricao: Descrição curta
description: Meta description para SEO
novo: true                        # Badge "NOVO"
imagens:
  - src: /assets/img/produto1.jpg
    alt: Descrição
imagemCard: /assets/img/card.jpg  # Thumbnail para listagem
ofertas:
  - marketplace: Amazon
    preco: "199.90"
    link: https://...
    freteGratis: true
caracteristicas:
  - Característica 1
  - Característica 2
especificacoes:
  Dimensões: 10x10x10cm
  Peso: 500g
video: https://youtube.com/embed/...
resumoIA: Resumo gerado por IA
conteudoExtra: <p>Conteúdo HTML adicional</p>
---
```

### Para Posts do Blog ✨ NOVO
```yaml
---
layout: post.njk
title: Título do Post
description: Meta description
tags: 
  - post                          # ⚠️ OBRIGATÓRIO
  - tag1
  - tag2
categoriaBlog: guias              # guias | noticias | dicas | reviews
imagem: /assets/img/blog/post.jpg
autor: Nome do Autor
date: 2025-01-20                  # YYYY-MM-DD
permalink: /blog/slug-do-post/
---
```
